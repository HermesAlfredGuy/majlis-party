## What the columns mean

* **Ties** — rounds where both teams scored the same. Identical bots tie often; that is expected, not a defect.
* **A – B wins** — decided rounds. With identical bots this measures the game, not skill: in a race the first message wins, so one side can sweep all 40 runs.
* **Team points** — the average payout each side banked, 100 for a win and 70 for a loss, 85 each for a level round.
* **Size-fair** — the verdict, tested directly: a synthetic round where every player on both sides scores the same must be called level, and a better nine-phone side must be able to beat a twelve-phone side. That is what stops headcount from buying a win.

## Known shape, honestly

* Every one of the 24 games is size-fair: the payout is computed from the average player on each side (`S.settleResult`), not from a summed team total. Before that fix a twelve-phone side beat a nine-phone side in 40 out of 40 runs of sixteen different games.
* The A – B column still shows sweeps in race games (word race, darts, qahwa, marathon). Those are identical bots being identical: the first correct message, not the bigger team, takes every run.
* Bots never vote, never cheer and never get tired, so this table says nothing about how a room feels.
* Bots are not people: this measures the *scoring rule*, not how much fun a room has. Fun is judged from captures and the 5-second rule card, not from this table.
